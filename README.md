> **Maison De Rose** is a state-of-the-art, editorial luxury web application engineered for a high-end Parisian floral bistro and celebration venue. Combining cinematic storytelling, interactive celebration planners, automated WhatsApp reservation pipelines, and an administrative lead console, this project represents the pinnacle of modern frontend architecture and experiential UI/UX.

---

## ✨ Key Features & Technical Highlights

### 1. 🎛️ Interactive Celebration Configurator
- Real-time event visualizer for **Birthdays, Anniversaries, Proposals, and Baby Showers**.
- 3 dynamic package tiers (**Classic, Premium, and Luxe Elite**) with dynamic pricing estimation, package inclusions list, and live visual preview updates.
- Automated payload dispatching that auto-populates the table reservation system.

### 2. 📲 Instant WhatsApp Booking & Lead Automation
- Frictionless guest reservation workflow connecting website users directly to the host team.
- Automatically compiles guest count, schedule, package details, and contact info into a pre-formatted WhatsApp booking message.
- Multi-channel entry points: Floating Reservation Widget + Sectional Booking Form.

### 3. 🛡️ Integrated Admin Lead Management Console (`/admin`)
- Password-secured management dashboard for the cafe management team.
- Live reservation tracker with real-time status updates (**New / Confirmed**), single-click confirmation, and lead deletion.
- Newsletter subscriber export and one-click bulk clipboard copy.
- Built-in lead simulation engine to test traffic and reservation payloads in development.

### 4. 🎭 High-End Editorial Motion & Visual Craft
- **GSAP Cursor Spotlight**: Interactive ambient gold lighting tracking mouse coordinates across hero sections.
- **Lenis Smooth Scrolling**: Inertia-based kinetic scrolling providing a luxury editorial feel.
- **Falling Rose Petals Engine**: HTML5 Canvas particle physics system simulating gentle rose petal drifts.
- **Confetti Particle Feedback**: Micro-interaction feedback for user actions and reservations using Canvas Confetti.
- **Infinite Marquee**: Fluid GPU-accelerated client testimonial carousel with pause-on-hover mechanics.

### 5. 🍽️ Dynamic Gastronomy & Menu Suite
- Filterable culinary catalogue across **Specialty Beverages, Main Courses, and Parisian Desserts**.
- Interactive heart-favoriting mechanics with micro particle explosions.
- Itemized nutritional indicators, calorie counters, and chef recommendation tags.

### 6. 🔍 Search Engine Optimization (SEO) & Schema Architecture
- Validated JSON-LD Structured Data for search engines.
- Rich OpenGraph and Twitter card metadata for high-converting social sharing.
- Evergreen category subpages (`/romantic-dining`, `/private-celebrations`, `/instagrammable-spots`, `/luxury-floral-cafe`).

## 🚀 Getting Started

### Prerequisites
- Node.js 18.x or higher
- npm, yarn, or pnpm

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/itzzavdheshh/maison-de-rose-luxury-cafe.git
   cd maison-de-rose-luxury-cafe
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Run the development server:**
   ```bash
   npm run dev
   ```

4. **Open in browser:**
   Navigate to [http://localhost:3000](http://localhost:3000)

5. **Access Admin Console:**
   Navigate to [http://localhost:3000/admin](http://localhost:3000/admin) *(Security Code: `rose123`)*
